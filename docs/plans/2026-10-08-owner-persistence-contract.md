## Wire and identities

Define `OwnerSaveV1`: eight magic bytes `NHOWNR01`, LE u32 envelope version=1, LE u64 body length, SHA-256 body digest, then canonical JSON UTF-8 body. Digest detects corruption, not authority. Canonicalization uses sorted object keys, integer-only numbers, no duplicate keys, unknown fields, trailing bytes or noncanonical spellings; bytes are lowercase hex. Strict parsing validates limits before allocation and re-encoding must equal the body. Version changes use explicit migrators.

Default hard bounds: 64 MiB complete wire, 16 MiB individual decoded payload, 65,536 rows per table, 262,144 aggregate reference edges, 256-byte names, nesting 32. Hex overhead counts against wire bounds. Host may narrow these and existing runtime limits; larger profiles require explicit admission, never inferred from saves. Checked arithmetic covers lengths, counters and reservations.

Body contains format/profile versions, capture epoch, module/current-dispatch tables, owner payload rows, publication/history rows, workflow rows, input rows, timer rows, retention edges, counters/tombstones and migration provenance. Each row has a typed `SaveId=(kind,u64)`; tables sort by ID. Ordered dependency slots, routes, events, ledger order and timer ties remain ordered arrays. Canonical storage ordering must not change effect ordering.

Module rows contain exact artifact digest, executable kind, ABI, manifest/config, extension target, dependency slots and declarative requested grants. Owners contain incarnation, generation/revision/schema digest, backend/codec/policy IDs, ports, dependency declarations and opaque owner-encoded bytes. Schema/codec/policy identities include stable name, version and artifact digest. Guest bytes may be embedded or fetched by exact digest. Native artifact identity is a trusted host build binding, not a machine-code hash.

Save IDs identify modules, owners, operations, leases, callbacks, pins, candidates, batches, cleanup participants, input services/records, timers and shared behavior reservations. Aliased references share one row/reservation. Persist high-water counters, retired IDs, consumed tickets and tombstones even after disposal; holes cannot be reused. Validate uniqueness, counter dominance, finite bounds and all edges. Historical origins may reference explicit disposed tombstones; required live edges may not.

Restore allocates fresh runtime namespaces for kernel/owner/input/timer/cleanup identities and maps every legitimate cross-link, including resource strings, permits, pipeline hashes, tickets and record provenance. Wire references use typed IDs rather than ambiguous embedded handles. Owner codecs declare/remap internal references. Old runtime-local digests are evidence only; recompute bindings from validated exact artifacts/routes. Expose only fresh trusted host handles/tickets after activation. Pre-save external credentials, detached observations and raw wire IDs remain invalid, even if serials coincide.

Metadata/opaque bytes are a temporary transport graph, never a live authoritative property database. Each restored owner receives its own typed allocation/blob/field buffer. Registry/coordinator retain routes, identities and retention evidence only. Derived caches are discarded and rebuilt through authenticated coherent queries.

## Ownership seams (proposed APIs)

Add `nethacked-persistence` for `SaveLimits`, strict `encode/decode`, typed wire tables and orchestration. `capture(&mut HostBundle, &SaveCatalog) -> Result<Vec<u8>>`; `prepare_restore(&[u8], &RestoreAuthority) -> Result<RestoreStage>`; `activate(&mut HostSlot, RestoreStage) -> Result<RestoredHandles>`. `HostSlot` owns the complete gate domain; no partial service replacement. These are host APIs, never guest constructors.

`RestoreAuthority` supplies allowlisted module/native factories, exact schema and codec resolvers, policy/profile/accounting/cleanup factories, migrations and approved grants. Saved source grants are requests, never destination credentials; destination host authority independently admits their effective scopes. Missing/narrowed grants needed by retained work refuse activation; fresh runtime calls still recheck current grants. No saved pin or manifest confers ambient authority. Hidden stages bind the destination authority identity and trusted epoch covering grants, module admission, resolvers and codec/policy changes; guest format/native-codec identities never select an unapproved factory.

In owners add `PersistenceCodec<T>` distinct from preparation: stable identity, bounded `encode_state(&T)`, `decode_state(bytes, &Remap) -> T`, `validate_state(&T)` and reference enumeration. Add host-resolved `validate_old_format(bytes, limits, old_schema) -> ValidatedOldState`: bounded decoding and semantic validation with the exact approved old schema/codec, without effects or transformation. Typed validation alone is insufficient. Pending support adds encode/decode for already constructed `Prepared<T>` next state, observations, events/reply and exact retained codec/policy/helper binding. Decoding constructs the sealed candidate without command preparation. Concrete typed native, Wasm-backed blob and private field codecs are mandatory; native purity/fidelity, alias exclusion and bounded work remain explicit trust assumptions tested with concrete implementations.

Owners keep codec calls within owner-local storage guards; publication restores receipts/epochs/consumed tickets and sealed batch accounting identities. No generic external candidate constructor. Kernel supplies sealed host-only capture/rebuild of registrations, grant requests, current attachments, complete retained routes, operations/leases/pins/callback origins; it never restores from an inspection descriptor alone.

Workflows own frame/program/ticket/cleanup reconstruction. Inputs own source-policy state, ledger/observations and replay binding reconstruction. Timers own task/profile state, callbacks and terminal cleanup reconstruction. Owner-services owns `Targets` weak routing, `Behavior<T>` captures/scopes and shared `Bundle` references. Each seam resides beside its private state; erased enrollment adapters contain no mutable payload aliases. Rust closures, pointers, `Rc`/`Weak` addresses, borrowed authority and callback trait objects are never serialized: factories reconstruct them by exact approved identities.

## Capture and restoration phases

1. **Quiesce:** host executor blocks invocation, scheduling, lifecycle, grant/dispatch changes and publication across the complete domain. Acquire the owner visibility gate and service guards in canonical order. Refuse active Wasm/native calls, intermediate swaps or running timer delivery; retry after they reach a safe boundary. A workflow `Running` between steps is supported. Barrier/codec failure releases guards with no effects.
2. **Capture:** reserve bounded scratch, encode each independent owner and service at one epoch; preserve accepted publication/event prefixes and delivery cursors, readonly dependencies, live prepared candidates/batches, consumed tickets and terminal cleanup obligations. Copy immutable graph metadata under the barrier. No sampling, domain preparation, callbacks, cleanup or lifecycle changes. Release only after complete coherent capture; immutable encoding can then finish outside the gate.
3. **Structural parse:** bounded untrusted envelope/table parse checks framing, lengths, IDs/counters and reference syntax; it cannot establish old owner semantics. OwnerSave wire strictness does not govern legacy native JSON.
4. **Resolve/validate/migrate:** host-resolve exact old format/schema/codec validator/decoder and authorize artifacts, ABI, manifest/grants and policies BEFORE semantic validation. Unknown or unavailable old schema/validator refuses even with an available migrator. Validate old payloads and complete ownership/reference invariants using `validate_old_format`; only validated old state enters pure bounded migrations. Validate transformed state with the exact target schema/codec before reconstruction; preserve continuation semantics. Resolve retained old code independently of current future dispatch. Missing old native codec or guest helper refuses; current behavior and re-preparation are forbidden substitutes.
5. **Build hidden host:** allocate fresh namespaces; instantiate owners separately; restore all cross-links, programs, input observations, retained closure graphs, reservations and cleanup participants. Revalidate local invariants, grants, schemas, target stamps, event prefixes, counters, capacities and complete reference graph; recompute reference counts rather than trusting claimed counts. No visibility, scheduling, callbacks or input policy transitions yet.
6. **Activate:** pre-reserve result handles; acquire shared destination/authority exclusion also used by grant narrowing/revocation and module/resolver/codec/policy updates. Immediately before exchange, check stage authority identity/epoch and current admission under that same guard, held through exchange. Changed epoch refuses and requires restaging; no unsynchronized check-then-swap. Atomically exchange one validated `HostBundle`, then open visibility. Activation contains no fallible codec/factory/callback work. Before exchange, every failure preserves destination state, effects and credentials. Detached staging/destructors must be effect-free and panic-contained; arbitrary effectful native factories are unsupported. Retire the old bundle after exchange under the accepted quarantine/fail-stop destructor policy; this is not rollback.
7. **Continue explicitly:** trusted host resumes fresh tickets, schedules deliveries or retries cleanup. No automatic callback at load. Previously accepted charges/draws/events/deliveries remain accepted exactly once; replay cannot allocate another record, republish a consumed ticket or rerun terminal callbacks.

Save returns bytes; it is not crash-atomic publication or a durable effects journal. Optional file storage separately specifies bounded temporary write, flush/fsync, same-filesystem atomic replacement and directory sync supported by that platform. Replacement failure retains the prior file where guaranteed; power-loss guarantees require platform evidence. A save cannot retract effects performed after capture or make external I/O exactly-once across crashes.

## Mandatory pending-state coverage

| State | Required representation/continuation |
| --- | --- |
| Paused charge/input workflow | Frozen `Program`, phase/sequence/status/local bytes/trace, exact ticket/lease, accepted charge and input prefixes, cleanup enrollment. Resume the next step, never restart the operation. |
| First preparation after replacement | Retained native codec, query policy and full old Wasm helper/import closure remain executable. Save before first query/preparation; restored work uses old closure, new work uses saved current dispatch. |
| Prepared batch | Sealed next payloads, stamps/readonly evidence, input observations, accounting identity, operation/checkpoint and unconsumed ticket; validate without re-preparing. Used tickets remain used. |
| Recorded inputs | Source bytes including RNG/provider cursor, exact policy/version, ordered ledger, per-operation ordinals/high-water counters, request/value/provenance and observation references. Replay validates accepted record and consumes no new draw. |
| Queued callback after source disposal | Full kernel callback closure/origin, source tombstone, target stamps, payload/deadline/residency/tie order, adapter scoped old codec references and shared reservation bundle; a live source lease is not required. |
| Terminal Busy cleanup | Workflow/timer outcome, accepted effects, invocation lease, participant identities and outstanding cleanup. Retry discard only, idempotently; retain code until cleanup succeeds. Cancelled tasks and terminal disposal preserve nonreuse. |

## Refusal matrix

| Trigger | Boundary/result; residual |
| --- | --- |
| Truncated, malformed, noncanonical, oversized; duplicate IDs/keys, overflow, dangling/cyclic-invalid edges | Decode/graph refusal, unchanged destination; corruption never migrates. Legal dependency cycles follow kernel rules. |
| Missing/changed artifact, ABI/schema/codec/policy; unsupported migration | Resolution refusal, unchanged destination; exact missing dependency reported. Explicit supported migrations require positive fixtures. |
| Forged/wrong incarnation, stale stamps, invalid scopes/grants, incomplete retained closure or cleanup graph | Admission refusal before visibility; bytes cannot repair authority. |
| Active call/publication/delivery or held guard | Capture Busy, retry at safe boundary; paused work, queued callbacks and terminal cleanup are supported, not blanket exclusions. |
| Opaque unregistered closure, effectful/nonrestorable codec/provider, threaded gate backend without exclusion proof | Explicit Unsupported; enrollment names required codec/backend successor. D1–D4 must support all accepted native/Wasm owners and states above before A5 closure. |
| External destructive input/I/O or crash recovery | No rollback/exactly-once guarantee; buffered recorded source is supported. Durable adapter/journal is a separately named successor, not substituted for required recorded-input coverage. |
