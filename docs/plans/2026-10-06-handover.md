# Handover — 2026-10-06

## Principles (from the user, binding)

- **No C at runtime, anywhere.** C (`NetHack-5.0.0/`, tag `NetHack-5.0.0_Released`)
  is a source of facts only: tables are text-expanded with `cc -E` and
  extracted to TOML. Engine and behaviour stay Rust.
- **Data-driven, not hand-ported.** Facts come from the C tables via the
  extractor; Rust holds behaviour as one handler per C tag (AD_*, AT_*, M1/2/3
  flag, object id), citing C `file:line`.
- **No legacy/backward compatibility needed.** Re-baseline goldens when data or
  RNG order legitimately changes (say so in the commit).
- **Token-efficient:** work inline, no agent fleets, minimal tool output
  (tail/grep), terse updates (Ukrainian with the user).
- Git: per-command `GH_TOKEN=$(gh auth token -u dmytro-yemelianov)` and
  `git -c credential.helper= -c credential.helper='!gh auth git-credential' push`;
  never switch gh accounts globally; never force-push. Merge PRs with `--merge`
  once CI is green (GitHub runner "not acquired" cancellations = rerun).

## Pipeline (merged in #14–#17)

```
NetHack-5.0.0/include/*.h, src/mkobj.c, src/role.c
  └─ scripts/extract/c_tables.py   (cc -E with our own table macros; every symbol
     │                               validated against C headers; --check)
     ▼
data/nethack-5.0/{objects,monsters,artifacts,class_probs,roles,races}.toml
  └─ scripts/extract/gen_rust.py    (C vocabulary -> Rust types; --check)
     ▼
crates/nethacked-data/src/generated/{items,monsters,roles}.rs
```

- Ids: `MonsterSpeciesId` / `ItemKindId` are index newtypes named exactly as C
  (`MonsterSpeciesId::ALIGNED_CLERIC`, `ItemKindId::WAN_WISHING`,
  `ItemKindId::ART_EXCALIBUR`), serialized as the C name (`src/c_id.rs`).
- Counts: 383 species, 440 object kinds + 23 unnamed appearances, 33 artifacts,
  13 roles, 5 races.
- CI (`lean_action_ci.yml`, docs job) sparse-checks out the C tag and runs
  `c_tables.py --check`, `gen_rust.py --check`, `behaviour-coverage.py --check`.
- `scripts/behaviour-coverage.py` → `docs/parity/behaviour-coverage.md`: which
  AT/AD/object kinds engine code references (heuristic, not fidelity).
- Generation: `nethacked-data/src/generation.rs` (`rndmonst_adj`, `mkobj_kind`),
  rooms filled in `sim/actions/stairs.rs` like `mklev.c`.
