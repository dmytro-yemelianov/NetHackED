# NetHack Fidelity D3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Align initial player alignment record per role with NetHack 5.0 C (`urole.initrecord`) and implement canonical monster malign computation and kill-based alignment adjustments (`mon.c:3676-3726` and `makemon.c:2330-2366`).

**Architecture:** Pure core functions in `netrust-core` compute `calculate_malign` and apply `adjalign`; `netrust-data` provides `initial_alignment_record` on roles; `netrust-arena` stores `malign` on `ActorRecord`; `netrust-sim` orchestrates spawn-time malign setting and death alignment adjustments.

**Tech Stack:** Rust 1.88.0 (pinned), proptest 1.5, Lean 4.30 / Lake.

**Spec:** `docs/superpowers/specs/2026-10-05-fidelity-d3-design.md`
**C reference:** `docs/superpowers/specs/2026-10-05-fidelity-d3-c-reference.md`
