# NetHack Fidelity D2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Monster/item/pantheon data match NetHack 5.0 C and the simulation uses it (attacks with dice, weapon damage, armor AC, peacefulness).

**Architecture:** Data tables in `netrust-data` become C-faithful and richer (attack lists, size, flags, wand direction, magic); pure `netrust-core` combat/AC functions consume them with explicit rolls; `netrust-sim` maps actors to archetypes by name and draws rolls; Lean models updated where formulas change.

**Tech Stack:** Rust 1.88.0 (pinned), proptest 1.5, Lean 4.30 / Lake.

**Spec:** `docs/superpowers/specs/2026-10-04-fidelity-d2-design.md`
**C reference (binding values, current mismatches, code locations):** `docs/superpowers/specs/2026-10-04-fidelity-d2-c-reference.md`
