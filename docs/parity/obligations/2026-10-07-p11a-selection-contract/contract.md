## Ready backend prerequisite

P11a-S1 adds a separate `ZapSelectedWand { item_index: u32, expected_item: Option<SlotId>, dir: Direction, energy: u32 }` and `CancelZapSelection`. It keeps the existing `ZapWand {dir,energy}` serialized form, old parser `zap` omission/index-ignore/East/default6 behavior and legacy golden paths unchanged. `expected_item` defaults to None and omits on serialization. Complete direct-carried inventory indices precede wand filtering; a captured generational token verifies that the chosen current index still identifies the same carried object. An index-only request refers to the current snapshot and cannot prove an old choice was not displaced.

The native action and shared parser are the first coherent prerequisite. `zap_selected` requires a bounded u32 index, defaults compass direction East only for this interim complete-action API, and uses ZAP_ENERGY6. `cancel_zap_selection` is explicit and rejects nonnull action arguments. Missing selection is an error, never inferred cancellation or first-wand fallback. Malformed transport input returns its normal error envelope without calling `session.step`. This API is not the eventual charged prompt continuation interface.

Selection validates current complete-inventory range, optional token equality, Wand class, then the accepted owned definition lookup, all before charges, effects or scheduler energy. Range/missing/stale emits exactly `You don't have that object.`; nonwand emits `That is a silly thing to zap.`; unknown explicit identity reuses `You cannot zap that wand: its definition is unavailable.`. Explicit cancellation emits `Never mind.` under pinned verbose=true. There is no beam/creation/effect event and no charge/RNG/time draw for these exits. Canonical gameplay state and native RNG remain unchanged in a living, ready, reconciled fixture; event_log and AgentSession.last_events intentionally record the refusal/cancel message. Existing helpless/dressing replacement with Wait is retained and tested as a distinct boundary.

Success dispatches the exact selected item through the existing shared wand handler. No signed-charge, wrest, backfire or direction pipeline change is authorized in S1. A positive2 uncursed owned canonical create-monster/NoDir witness decrements only that wand to1, ignores compass/energy as the accepted ordinary create path already does, retains the first bound23 draw and optional bound7 count draw, P10 placement/HP/group draws and NORMAL_SPEED scheduler ordering.
