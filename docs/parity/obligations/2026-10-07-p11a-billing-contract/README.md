# Unpaid-wand debt contract

If an unpaid wand is consumed, it leaves inventory while its shop debt remains. P11a-P1-BILL defines a retained receipt owner, frozen known quantity/price/account terms, explicit unknown legacy terms, and atomic refusal of unsupported ledger clearing or payment. Quantity1/3, canonical/custom identity, stale generations and repeated admission have concrete fixtures. This is a reviewed prerequisite contract; no billing implementation or full wand-family acceptance is claimed.
