# NetHackED vs NetHack 5.0: Parity Tables

These tables compare NetHackED with the NetHack 5.0 C source, one player-visible feature per row. They are what [the roadmap](../roadmap.md) is planned and measured against.

**Audit baseline:** 2026-10-05, NetHackED `main` @ `cdd7f2d` (v0.3.0 plus the pixel renderer). C reference: the NetHack 5.0.0 tree (`src/`, `include/`, `dat/`).

## How to read the tables

| Status | Meaning |
|---|---|
| ✅ PRESENT | Works for the player the way it does in C. Small, documented deviations are noted in the row. |
| 🟡 PARTIAL | Exists but is reduced or different (fewer cases, simplified formula, missing side effects, reachable only from one frontend or only through the agent API). |
| ❌ MISSING | A player cannot reach it. Code that exists but is never called in normal play counts as missing. |
| ❔ UNSURE | The audit could not confirm the behavior. The row says why. |

Each row gives:
- the **C reference** (file and function or line);
- the **evidence** in NetHackED, as a Rust `file:line` or as a grep that found no match;
- the **player impact** in one line.

Paths in the evidence are shortened: `sim/` = `crates/nethacked-sim/src/`, `core/` = `crates/nethacked-core/src/`, `data/` = `crates/nethacked-data/src/`, `types/` = `crates/nethacked-types/src/lib.rs`.

**Method.** The baseline was produced by reading both trees, with one pass per area. Every status was checked against the code; none was inferred from names or docs. `docs/formal-mechanics-spec.md` ("Known divergences") was cross-checked. A row whose gap is already documented there says so.

**Keeping it honest:**
- A pull request that changes a feature updates its row (status and evidence).
- It then runs `python3 scripts/parity-summary.py`, and CI fails if the summary below is stale (`--check`).
- A status only moves to ✅ when a test covers the C behavior.
- Each release states the counts below.

## What already matches C closely

These ✅ rows are worth keeping intact while the gaps are filled:
- monster melee to-hit and damage (`mattacku` dice);
- peacefulness at creation (`peace_minded`);
- kill-based alignment and anger rules (`mon.c`, `setmangry`);
- armor class from worn armor (`find_ac`);
- hunger thresholds and starvation;
- luck timeout and the luckstone;
- boulder pushing;
- Elbereth scare rules;
- scroll of genocide and charging (including the explosion formula);
- the invocation ritual (Bell, Candelabrum, vibrating square, Sanctum);
- stairs, branch stairs and level persistence.
